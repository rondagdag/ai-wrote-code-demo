## Entities

### Song (existing)

Defined in `src/types/Song.ts`. Read by the vote endpoint; `votes` field is mutated by
the repository's `vote()` method.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `string` (UUID) | Primary key; generated by repo via `randomUUID()` |
| `title` | `string` | 1–200 chars |
| `artist` | `string` | 1–200 chars |
| `submittedBy` | `string` (user ID) | Set at creation; immutable |
| `votes` | `number` | Running total; updated by `vote()` |
| `createdAt` | `Date` | Set at creation; immutable |

### VoteRecord (repository-internal)

Stored in `SongRepository.songVoters: Map<songId, Map<userId, direction>>`.
Not exported as a TypeScript type; internal to the repository.

| Field | Type | Notes |
|-------|------|-------|
| `songId` | `string` (UUID) | Key in outer Map |
| `userId` | `string` | Key in inner Map |
| `direction` | `'up' \| 'down'` | Value in inner Map; updated on toggle |

**Future PostgreSQL mapping**:
```sql
CREATE TABLE votes (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  song_id     UUID NOT NULL REFERENCES songs(id) ON DELETE CASCADE,
  user_id     UUID NOT NULL,
  direction   VARCHAR(4) NOT NULL CHECK (direction IN ('up', 'down')),
  created_at  TIMESTAMPTZ DEFAULT NOW(),
  updated_at  TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE (song_id, user_id)
);
CREATE INDEX idx_votes_song_id ON votes(song_id);
```

## Repository Changes

### `SongRepository` (updated)

**Changed**: `songVoters` inner collection type from `Set<string>` to `Map<string, 'up' | 'down'>`.

**Removed**: `hasUserVoted()` and `recordVote()` — replaced by `vote()`.

**Added**: `vote(songId, userId, direction)` — single method encapsulating all toggle logic.

```typescript
vote(songId: string, userId: string, direction: 'up' | 'down'): VoteResponse | undefined {
  const song = this.songs.get(songId);
  if (!song) return undefined;

  const voters = this.songVoters.get(songId) ?? new Map<string, 'up' | 'down'>();
  const existing = voters.get(userId);

  if (existing === direction) {
    // Toggle off: same direction → remove vote
    voters.delete(userId);
    song.votes += direction === 'up' ? -1 : 1;
    userVote = null;
  } else if (existing !== undefined) {
    // Change direction
    voters.set(userId, direction);
    song.votes += direction === 'up' ? 2 : -2;
    userVote = direction;
  } else {
    // New vote
    voters.set(userId, direction);
    song.votes += direction === 'up' ? 1 : -1;
    userVote = direction;
  }

  this.songVoters.set(songId, voters);
  return { songId, votes: song.votes, userVote };
}
```

## State Transitions

```
                  ┌──────────────────────────────────────────────┐
                  │               Song Vote State                │
                  │  (per user per song)                         │
                  └──────────────────────────────────────────────┘

   [No Vote]  ──── vote('up') ────►  [Voted Up]
       │                               │    │
       │                        vote('up')  vote('down')
       │                               │    │
       │◄──── vote removes ────────────┘    │
       │                                    ▼
       │◄──── vote('down') ────  [Voted Down]
       │                               │
       │                        vote('down')
       │                               │
       └◄─────── vote removes ─────────┘
```

## Validation Rules

| Input | Rule | Error |
|-------|------|-------|
| `req.params.songId` | Must be a valid UUID v4 | 400 `VALIDATION_ERROR` |
| `req.body.direction` | Must be `'up'` or `'down'` | 400 `VALIDATION_ERROR` |
| Auth token | Must be present as `Bearer <token>` | 401 `UNAUTHORIZED` |
| Song existence | Song with `songId` must exist in repo | 404 `NOT_FOUND` |
| Rate limit | Max 10 vote changes/min per user | 429 `RATE_LIMITED` |

## No New Database Migrations Required

The current implementation is in-memory. The SQL schema in this document is a forward
reference for when PostgreSQL is introduced. No migration files are created by this feature.
